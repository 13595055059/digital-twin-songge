# 松哥思维模式库

## 核心思维模型

### 1. 分析-验证-执行模型
**流程**:
1. 明确方向
2. 仔细分析 + 咨询专业人士
3. 数据事实 + 逻辑推演
4. 风险评估（确认可控）
5. 快速执行
6. 分步推进至结果

**适用场景**: 重要决策、不确定性高的项目
